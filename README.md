# Лендинг питомника мальтипу

Одностраничный продающий лендинг: статичные HTML/CSS/JS, Vite — только для разработки и сборки.
Структура объединяет maltipoo-official.com (порядок блоков, каталог, калькулятор, подарок, гарантии) и maltipoo.net (бейдж доверия, «Растим как членов семьи», 6 шагов покупки, баннер видеозвонка, плавающая кнопка WhatsApp). Цвета — окрасы мальтипу: крем, абрикос, ред/карамель, шоколад. Шрифт — Manrope.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # готовый сайт в dist/ — его и загружать на хостинг
```

## Где что менять

- `src/data.js` — **щенки** (`PUPPIES`: имя, пол, возраст, окрас, вес, цена, статус `available` / `reserved` / `sold`, фото, описание), отзывы (`REVIEWS`: имя, город, кличка щенка, дата, источник, фото, текст), вопросы-ответы, вопросы калькулятора, фото для карусели и галереи. Каталог показывает по 6 щенков, дальше — кнопка «Показать ещё».
- `public/img/` — фото. Сейчас там **временные** фото с Wikimedia Commons (CC BY / CC BY-SA / CC0, авторы — в `CREDITS` и в подвале по ссылке «Авторы фото»). Замените на свои и удалите `CREDITS`.
- `index.html` — тексты блоков, телефон, мессенджеры, адрес, реквизиты.
- `src/main.js` → `submitLead()` — отправка заявок (CRM / Telegram-бот / почта). Сейчас заявка только пишется в консоль.
- `src/styles.css` — цвета и отступы в `:root`: колонка `--container` (шапка выровнена по ней), ритм секций `--section`, отступ заголовок → контент `--head`, промежутки `--gap`, внутренние отступы `--pad`.

Всплывающие окна появляются с масштаба 95 %.
