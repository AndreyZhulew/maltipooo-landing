# Лендинг питомника мальтипу

Одностраничный продающий лендинг: статичные HTML/CSS/JS, Vite — только для разработки и сборки.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # готовый сайт в dist/ — его и загружать на хостинг
```

## Где что менять

- `src/data.js` — **щенки** (`PUPPIES`: имя, пол, возраст, окрас, вес, цена, статус `available` / `reserved` / `home`, фото, описание), отзывы, вопросы-ответы, вопросы квиза. Счётчик «в наличии» и фильтры считаются автоматически.
- `public/img/` — фото. Сейчас там **временные** фото с Wikimedia Commons (CC BY / CC BY-SA, авторы перечислены в `CREDITS` и в подвале по ссылке «Авторы фото»). Замените на свои и удалите `CREDITS`.
- `index.html` — тексты блоков, телефон, мессенджеры, адрес, реквизиты в подвале.
- `src/main.js` → `submitLead()` — отправка заявок (CRM / Telegram-бот / почта). Сейчас заявка только пишется в консоль.
- `src/styles.css` — цвета, шрифты (Unbounded + Golos Text) и отступы в `:root`: колонка `--container` (шапка и гигантские заголовки выровнены по ней), ритм секций `--section`, отступ заголовок → контент `--head`, промежутки `--gap`, внутренние отступы `--pad`, толщина обводок `--bw`.

## Что работает

- Каталог с фильтрами, статусами («В наличии», «Забронирована · Марина», «Нашёл дом») и карточкой щенка во всплывающем окне.
- Кнопка «Забронировать» открывает форму с подставленным щенком; все формы — с маской телефона и выбором мессенджера.
- Подбор щенка — чат с заводчиком: вопросы «печатаются», ответы кнопками, в конце форма прямо в чате.
- Всплывающие окна появляются с масштаба 95 %.
- На телефоне снизу закреплена панель «позвонить / WhatsApp / выбрать щенка».
